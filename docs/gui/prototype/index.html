H3PHP GUI 需求原型

需求依据 task_plan.md Phase 20–30、findings.md UI 流程图、progress.md Phase 30 接入记录逆向整理；完整条目见 docs/gui/GUI_PRD.md 与 agents/prd.json。

原始目标（v2.0）：跨平台（macOS / Windows / Linux）+ 多后端（Native H3 / ComfyUI / HTTP API）+ Qt GUI 工作流编辑器，且 既有 CLI 工作流保持不变。
v2.1 追加：ComfyUI 下载安装、模型权重下载管理、环境检测 UI、首次启动向导。

关键约束

线程模型PHP 事件循环 + onTick，禁止阻塞
