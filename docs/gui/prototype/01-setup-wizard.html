Welcome to H3PHP

This wizard helps you set up H3PHP for MiniMax-H3 video generation.

H3PHP is a cross-platform GUI supporting Native H3, ComfyUI, and HTTP backends.

How to use / 使用说明：

  1. Select a model directory (Model Dir)
  2. Enter a prompt describing the video
  3. Choose resolution, frames and steps
  4. Click Generate and wait for the MP4
